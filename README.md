# AgentFlow Ops

AgentFlow Studio 작업을 돕는 작은 자동화 조립 저장소입니다. 로컬에서 연 총괄 세션이 웹 Pro·Claude·Codex Cloud에 범위를 나눠 맡기고, GitHub에 남은 결과를 읽어 판단·통합합니다.

기존 노트북의 대화·브라우저 세션이 계정 변경 뒤에도 유지되는 환경을 전제로 합니다. 오픈소스와 기존 CLI를 재사용하고, 우리 작업에 필요한 연결만 추가합니다.

## 현재 진행

2026-10-23: 공급된 오픈소스 코드와 현재 로컬 CLI를 조사하고 초기 조립 중입니다. 웹 Pro는 Oracle을 우선 검토하며, 실제 배포판의 기능과 최신 소스의 기능을 구분해서 확인하고 있습니다.

자동 계정 전환·브라우저 질문 왕복·DeepSeek 실행을 완료했다고 판정한 단계는 아닙니다. 설치·실행 근거와 남은 연결 지점은 후속 문서에 기록합니다.
